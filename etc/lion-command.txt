LION CLONE TO CRUCIAL 1TB & RAID RESTORE | 2026-09-17n (session 01a0af84)

PLAN: Kingston (240GB) -> Crucial MX500 (1TB) -> WD back to Bay 2 (Raid X restored)

STEP 1 — ERASE CRUCIAL IN DISK UTILITY (Booted on Kingston):
1) Open Disk Utility.
2) In sidebar, select the Crucial volume (currently "start disk clone").
   (Or select the outer "1 TB CT1000MX500SSD1" row -> Partition -> 1 Partition, GUID).
3) Click Erase tab:
   - Format: Mac OS Extended (Journaled)
   - Name: e.g. "Macintosh HD" (or "Crucial SSD")
   - Click Erase.
   This cleanly wipes the old 900 GB bloat and frees all 1,000 GB!

STEP 2 — CCC CLONE (Kingston -> Crucial):
1) Open Carbon Copy Cloner.
2) Source: "Kingston" (running system).
3) Destination: "Macintosh HD" (the freshly erased 1TB Crucial).
4) Preset: "Backup everything" (or Maintain a backup).
5) Click Clone and allow it to complete. CCC will make it bootable.

STEP 3 — TEST BOOT CRUCIAL:
1) System Preferences -> Startup Disk -> select "Macintosh HD" -> Restart.
2) Confirm clean boot into the 1 TB Crucial SSD.

STEP 4 — RESTORE RAID X:
1) Shut down Mac Pro fully.
2) Remove Kingston SSD from Bay 2.
3) Put the WD Green HDD back into Bay 2.
4) Power on -> Mac boots from Crucial in Bay 1, Raid X reassembles with all 3 WDs!
